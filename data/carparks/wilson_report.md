# Wilson Parking – Greater Brisbane car parks

Generated by `data/carparks/raw/wilson/build_wilson.py` from cached raw responses (no data invented; unknowns are `null`).
Output: `data/carparks/wilson.json` (45 records).

## Method / endpoints

1. `robots.txt` checked first (`raw/wilson/robots.txt`): only `/EPiServer/CMS/` and `/Util/` are disallowed; nothing we used is disallowed.
2. `sitemap.xml` (cached `raw/wilson/sitemap.xml`): 66 QLD car park detail URLs (`/parking-locations/queensland/<area>/<slug>/`, list in `raw/wilson/qld_urls.txt`).
3. **JSON endpoint** (found via browser network inspection of the Brisbane CBD area page, which calls it from its map):
   `GET https://www.wilsonparking.com.au/api/v2/GetParkingByLocation?pageid=23413&latitude=-27.46777640825&longitude=153.029420017695&carParkFeature=undefined&sort=undefined&distance=100`
   Returns `carParks[]` with name, address, lat/lng, carParkNumber, openingTimes, heightRestriction, phone, carParkFeature, services, flags (`evChargerIsAvailable`, `disabledParkingIsAvailable`, `spottIsAvailable`, `isWilsonOne`, `canBookABay`), plus a partial `rates[]`. distance=20 and 50 both gave the same 45 Brisbane sites; distance=100 adds Gold/Sunshine Coast (54 total). Filtered to bbox lat -27.75..-27.0, lng 152.65..153.35 → **45**.
   Cross-check: every Brisbane-area sitemap URL is in the API set and vice-versa (0 missing either way).
   Also seen: `/api/v2/GetsurroundingParking?pageId=<id>` (detail-page "nearby" map; similar data, not needed).
4. **Detail pages** (all 45 fetched once, cached in `raw/wilson/pages/`): server-rendered HTML with the full rate accordion (`.accordionBlock-item`): *Prepay Online*, *Spott*, *Hourly*, *Night*, *Weekend*, *Daily*, *Event Rate* blocks, each with column headers (`Online` / `Drive up` / `Spott drive in`), rows and notes. Also parsed: monthly subscription cards, EV charger block, page notice, "Entry: … (Height: x m)". The API `rates[]` lacks online prices and Prepay/Spott blocks, so rates come from the HTML.
5. Politeness: curl with a normal Chrome UA, ≥1.1 s between requests, every response cached and never refetched (`raw/wilson/fetch.py`, log `raw/wilson/fetch_log.jsonl`). 53 requests total: 51×200, 2×401. The two 401s were the first two tries with Python urllib (probably Cloudflare reacting to the client). After switching to curl there were no 401/403/429 errors.

## Normalisation rules (schema + extensions)

- `price_aud` = drive-up price; `online_price_aud` = online prepay **or** in-app price (Spott / pay-by-phone). `channel` (extension) tells which: `drive_up`, `online`, `online+drive_up`, `spott_app`, `hotel_patron`. `source_block` (extension) = the page accordion it came from.
- "varies from $a - $b, depending on demand" → lowest price in the price field + `price_range_aud: [a,b]` (extension).
- **Early bird**: Wilson Brisbane has no drive-up "Early Bird" product on any page (the `Early Bird Parking` feature tag still shows up on several). The only early-bird-shaped products are **Spott Saver** rows (entry 6–9:30am, exit window same day, app only). These are `kind: early_bird`, `channel: spott_app`, with entry/exit windows taken from the next row on the page.
- **Flexi Saver** (online prepaid, price depends on demand) → `kind: flat`, `channel: online`. The page gives no entry/exit window for it.
- Hourly bands → `duration_hours_from/to` (minutes are converted, e.g. 20 min = 0.3333). Rows whose label says "daily maximum"/"max daily" → `kind: daily_max`. An open-ended top band without that wording stays `hourly` with `duration_hours_to: null`.
- Night/weekend: days come from the label ("Mon - Fri", "Weeknights", "Sat or Sun"). Entry/exit windows come from regexes over the label and notes. If the notes say weekend rates apply on public holidays, `+ public holidays` is added.
- Multi-day cruise rates → `kind: other` + `days_count` (extension). Motorbike, overnight, event, market and Riverfire rows → `kind: other`.
- Duplicates removed: "Night from"/"Weekend" rows in the Prepay Online block are dropped when a Night/Weekend block row already has the same online price. Cruise P3 Prepay multi-day rows are dropped when the Daily block has the same online price.
- `hours` is built from API `openingTimes` (identical consecutive days merged; "Monthly subscribers" listed separately).
- `height_m`: lowest "Height: x m" in the page entry text, falling back to API `heightRestriction`. The API uses 0 when not stated, which is treated as null.
- `features` = API `carParkFeature` tags as given (this includes marketing tags such as "Summer Sale", "Riverfire", "Dine BNE", "Elevate", "LPR"), plus "EV charging" / "Disabled parking" when a flag or the page says so. `ev_charging` and `accessible_parking` are `true` only when the source says so; otherwise `null`, never `false`.
- `discounts` = Spott, Prepay online, Wilson App pay-by-phone, Wilson Parking Card, monthly subscription prices, hotel-patron and tenant-visitor freebies.
- `id` = `wilson-<carParkNumber>`.

## Problems / caveats

- **Capacity**: no Brisbane page or API record states a capacity, so it is null for all records. The one count found is "4 bays" of EV charging at Cruise Terminal P1, kept in notes.
- **EV**: only Cruise Terminal P1 has an EV charger block (free casual charging, 4 bays, Type 2/Type 1). `evChargerIsAvailable` is false everywhere else, and `ev_charging` is left null rather than false.
- **Accessible**: `disabledParkingIsAvailable` is true at 9 sites. For the rest it is not stated, so null.
- **Height conflict**: at Cruise Terminal P1 the page says 3.00 m and the API says 2.5 m. The page value is used and the conflict is noted in the record.
- Prices that change with demand (Flexi Saver, Weekend online) are snapshots of the "from" price or range at `checked_at`. Wilson says online rates include a platform fee.
- At 119 Charlotte St, the Night notes give different windows for drive-up and online. The regex picks up the first (drive-up) window, and the full text is kept in `conditions`.
- The `Early Bird Parking` feature tag appears on several CBD sites, but no drive-up early bird rate is published on any page. Only Spott Saver exists (see above).
- Some API addresses have no suburb (e.g. "60 Edward St"). `suburb` (extension) is filled from the API region name.
- Hours for Cruise Terminal car parks show 24 h in the API, but the page notice says P1 is "only open to the general public on cruise ship days" (kept in notes).
- Brisbane Airport is not a Wilson site; no Wilson car parks were found in Ipswich, Logan, Redcliffe or Moreton Bay (the API sorts by distance, so none exist within 100 km beyond the 45 + coast sites).

## Re-running

`python3 data/carparks/raw/wilson/build_wilson.py` rebuilds from cache. Remove a file under `raw/wilson/pages/` to refetch that page.
